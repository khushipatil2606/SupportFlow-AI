# 🤖 SupportFlow AI

An Agentic AI-powered customer support platform that helps users manage orders, products, cancellations, and support tickets through a conversational AI interface.

## 🚀 Features

- 🤖 AI-powered customer support using Google Gemini
- 📦 Check order status
- 🛍️ View product details
- 📋 View order history
- 🎫 Create support tickets
- 📑 View support ticket history
- ❌ Cancel orders with confirmation
- ⚠️ Priority-based support tickets
- 💬 Conversational chat interface
- ⌨️ Typing indicator
- 🔄 Real-time frontend-backend communication
- 🗄️ Database-backed order and ticket management
- 🔐 Environment-based API key configuration
